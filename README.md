# BerryStrongBot
딸기를 인식해서 수확하는 로봇 프로젝트

## 💻 프로젝트 소개
- YOLOv5와 DOFBOT을 사용해 딸기를 수확하는 프로젝트
<br>

## ⏰ 개발기간
- 2023.09.13 ~ 2024.01.09

## 🙋 구성원
- 배윤재 : HW
- 홍서영 : SW(학습, 좌표 계산, 서버)
- 유성경 : SW(라벨링, 숙성도 계산)

## ⚙️ 개발 환경
- python3.9
- ubuntu18.04
- Database : MySQL
- HardWare : DofBot, Jetson Nano
- YOLOv5
- ROS

## 📃 기획 배경
- 초고령화로 인한 농촌지역의 노동력 부족문제를 해결하기 위해 수확로봇 프로젝트를 기획함
- 과채 중 노동시간이 가장 많은 딸기를 채택함

## 📌 주요 기능
#### 익은/안익은 딸기 학습 
#### 익은 딸기의 숙성도 계산
#### 딸기 꼭짓점 좌표 계산
#### 좌표 전달과 DB에 저장
#### 숙성도 70% 이상일 때 로봇팔로 수확
